## 📖 About the Project

**Talvo Desktop** is a complete management system designed specifically for pharmacies and medical supply stores. It provides everything you need to manage your business from one place, with full Arabic language support and a modern user interface.

### 🎯 The Problem It Solves

Pharmacies and medical supply stores struggle with:
- ❌ Scattered data across different systems
- ❌ Difficulty managing inventory and batches
- ❌ Inability to connect branches together
- ❌ Weak and inaccurate reports
- ❌ High costs of existing systems

### ✅ The Solution Talvo Provides

- ✅ **One system** for everything (sales, purchases, inventory, customers)
- ✅ **Complete inventory management** with batch tracking and expiration dates
- ✅ **Branch linking** remotely via Cloudflare Tunnel
- ✅ **Advanced reports** exportable to Excel and PDF
- ✅ **One-time payment** — no monthly subscriptions

## 🚀 Quick Start

### 📋 Requirements

| Requirement | Minimum | Recommended |
|-------------|---------|-------------|
| **Operating System** | Windows 7 SP1 | Windows 10/11 |
| **Memory** | 4 GB RAM | 8 GB RAM |
| **Storage** | 500 MB | 1 GB |
| **Display** | 1280×720 | 1920×1080 |
| **Internet** | Required for sync | Fast internet |

### 📦 Installation

1. **Download the installer:**
   [Talvo_Setup_1.0.2.exe](https://github.com/talvoapp/talvo-desktop/releases/latest)

2. **Run the file:**
   ```
   Talvo_Setup_1.0.2.exe
   ```

3. **Choose additional tasks:**
   - **For Master devices:** Select "Install Talvo Server Service" and "Install Cloudflare Tunnel Service"
   - **For Branch devices:** Don't select any service

4. **Run the application:**
   - **Master:** Enter `license_key` + `username` + `password`
   - **Branch:** Enter `branch_code` + `username` + `password`
